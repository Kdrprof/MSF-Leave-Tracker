# متتبع الإجازات — Leave Tracker

تطبيق أندرويد يعمل **بالكامل بدون إنترنت** لتتبع الإجازات ورصيد الإجازة السنوية حسب سليب الراتب.

## القواعد
- كل سليب يضيف **+2.08** يوم.
- الإجازة السنوية (Holiday) التي يبدأ **أول يوم** فيها بين 1 و15 → سليب نفس الشهر. من 16 فما فوق → سليب الشهر التالي.
- الإجازة تُحسب **كاملة في سليب واحد ولا تُقسم**.
- جميع الأنواع (Sick, Personal, Training, Unpaid, Compassionate) تُحسب في المجاميع والسجل والتقويم، لكن **Holiday فقط** يظهر في السليب.
- عدد الأيام يُكتب كما في نموذج الطلب: 0.5 أو 1 أو أكثر.

## الميزات
- الرصيد المتبقي بخط كبير في الرئيسية + مجموع كل نوع + المجموع الكلي.
- السجل مع بحث وفلترة ومجاميع شهرية، والتعديل والحذف (مع تراجع).
- تقويم سنوي ملوّن بمرجع الألوان.
- صفحة السليب بنفس خانات Paid leave: Previous / Accounted / Acquired / Remaining.
- إدخال يدوي، أو **تصوير/رفع نموذج الطلب** وقراءته بالذكاء الاصطناعي على الهاتف بدون إنترنت (Google ML Kit).
- كشف PDF شهري أو سنوي يُفتح بدون التطبيق.
- عربي / English، سحب للأسفل للتحديث، نسخ احتياطي واستعادة، مشاركة التطبيق نفسه.

## الحصول على APK
كل تعديل يُرفع لفرع `main` يُبنى تلقائياً على GitHub Actions (مجاناً) ويُنشر في Releases:
`https://github.com/Kdrprof/MSF-Leave-Tracker/releases/latest/download/Leave-Tracker.apk`

لا تحتاج تثبيت أي برنامج أو مكتبة: GitHub يحمّل كل المكتبات ويبني التطبيق على خوادمه.

## مفتاح التوقيع (مرة واحدة)
في GitHub: Settings ← Secrets and variables ← Actions:
- `SIGNING_KEYSTORE_BASE64` و `SIGNING_KEYSTORE_PASSWORD`

بدونهما يُبنى التطبيق بمفتاح مؤقت ولن تُثبّت التحديثات فوقه.
