# MSF Leave Tracker — متتبع إجازات موظفي أطباء بلا حدود (الأردن)

تطبيق أندرويد يعمل **بالكامل بدون إنترنت** لتتبع رصيد الإجازات حسب قواعد سليب الراتب:
- +2.08 يوم مع كل سليب شهري.
- الإجازة السنوية من 1 إلى 15 → سليب نفس الشهر. من 16 فما فوق → سليب الشهر التالي.
- الإجازة التي تمتد عبر يوم 15 تُقسم تلقائياً.
- 6 أنواع إجازات بألوانها (الإجازة السنوية فقط تُخصم من الرصيد).

## الحصول على ملف APK مجاناً (GitHub Actions)

1. أنشئ حساباً مجانياً على github.com (إن لم يكن لديك).
2. **New repository** ← الاسم: `msf-leave-tracker` ← اختر **Public** ← Create.
3. في صفحة المستودع الفارغ اضغط **uploading an existing file**.
4. فكّ ضغط ملف ZIP على الكمبيوتر، ثم اسحب **كل محتويات** مجلد `msf-leave-tracker` (بما فيها مجلد `.github`) إلى الصفحة ← **Commit changes**.
   - إذا لم يظهر مجلد `.github` (مخفي على ماك: اضغط Cmd+Shift+.)، أنشئه يدوياً: **Add file ← Create new file** واكتب الاسم `.github/workflows/build.yml` والصق محتوى الملف.
5. افتح تبويب **Actions** ← سيبدأ البناء تلقائياً (5–8 دقائق). إذا طُلب منك تفعيل Actions اضغط **Enable**.
6. عند ظهور ✅ افتح **Releases** (يمين صفحة المستودع) ← حمّل `MSF-Leave-Tracker.apk`.

**رابط دائم لآخر إصدار** (شاركه مع الزملاء):
`https://github.com/<اسم-حسابك>/msf-leave-tracker/releases/latest/download/MSF-Leave-Tracker.apk`

## التثبيت على الهاتف
افتح ملف APK ← إذا ظهرت رسالة «مصادر غير معروفة» اسمح للتطبيق (المتصفح/واتساب/الملفات) بالتثبيت ← تثبيت.
يتطلب أندرويد 8.0 أو أحدث.

## مفتاح التوقيع (مرة واحدة — مهم للتحديثات)
المفتاح لا يُحفظ في المستودع، بل في GitHub Secrets:
Settings ← Secrets and variables ← Actions ← New repository secret:
- `SIGNING_KEYSTORE_BASE64` = محتوى ملف المفتاح بصيغة base64
- `SIGNING_KEYSTORE_PASSWORD` = كلمة سر المفتاح

بدون هذين السرّين يُبنى التطبيق بمفتاح مؤقت، ولن تُثبّت التحديثات اللاحقة فوقه.

## التحديثات
أي تعديل ترفعه للمستودع يبني إصداراً جديداً تلقائياً، ويُثبّت فوق القديم **بدون حذف البيانات** (نفس المفتاح في كل بناء).

## المشاركة من داخل التطبيق (بدون إنترنت)
الإعدادات ← **مشاركة ملف التطبيق (APK)** ← واتساب / بلوتوث / Nearby Share.

## البيانات
- تُحفظ على الهاتف فقط، مع نسخة احتياطية تلقائية داخلية ضد التلف.
- عند تغيير الهاتف: الإعدادات ← حفظ/إرسال نسخة احتياطية ← ثم «استعادة» على الهاتف الجديد.
